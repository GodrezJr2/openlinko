# site/

Static landing page served at <https://jaylabb.my.id/openlinko/> (English) and `/openlinko/id/`
(Indonesian). Plain HTML, no build step; screenshots are copies of `docs/screenshots/v2-*`.

Deploy: zip `openlinko/`, upload it to `public_html` on the jaylabb.my.id host and unzip. The
sitemap (`openlinko/sitemap.xml`) is submitted in Google Search Console under the jaylabb.my.id
property.
